## How verdicts are reached

Each platform is probed by uploading a **signed** asset, re-fetching the
platform's processed copy, then comparing the Content Credentials before and
after:

- **PRESERVED** — the re-fetched asset carries the same manifest signer.
- **STRIPPED** — the manifest is gone and nothing is recoverable.
- **RE-SIGNED** — the manifest is present but signed by the platform, not the
  original signer.
- **SOFT-BINDING-RECOVERABLE** — the embedded manifest is gone, but a TrustMark
  soft-binding watermark survives, so provenance is recoverable via the
  [CAI Soft-Binding Resolution API](https://opensource.contentauthenticity.org/).

Re-attachment / signing is intentionally **not** rebuilt here — this tool
*consumes* Adobe TrustMark and the CAI Soft-Binding Resolution API rather than
reimplementing them. See the README for details.
